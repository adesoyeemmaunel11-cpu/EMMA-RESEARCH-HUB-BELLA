📘 Lesson 1: What Is Technology?

Technology is the use of knowledge, tools, skills, and processes to solve problems and make tasks easier, faster, or more effective.

🌟 Understanding Technology

Technology is all around us. Mobile phones, computers, the internet, medical equipment, transportation systems, and many other tools are examples of technology.

Technology is not limited to computers. It includes tools and methods that people develop to solve problems and improve the way we live and work.

💡 Why Is Technology Important?

Technology can help people communicate, learn, work, create, research information, solve problems, and develop new ideas.

🧠 Think About It

Look around you. Can you identify five examples of technology that you use every day?

🎯 Lesson Goal

By the end of this lesson, you should be able to explain what technology means and identify examples of technology in everyday life.

📘 Lesson 2: Computer Fundamentals

A computer is an electronic device that receives data, processes it, stores information, and produces useful results.

🖥️ What Is a Computer?

Computers are used for many activities, including learning, communication, research, business, entertainment, and creating digital content.

⌨️ Input Devices

Input devices allow a user to enter data or commands into a computer.

Examples include a keyboard, mouse, microphone, scanner, and webcam.

🖥️ Output Devices

Output devices present information produced by a computer to the user.

Examples include a monitor, printer, speakers, and projector.

💾 Storage

Storage allows digital information to be saved for later use. Examples include hard drives, solid-state drives, memory cards, and USB flash drives.

⚙️ Basic Computer Process

A simple way to understand computer operation is:

Input → Processing → Output → Storage

🎯 Lesson Goal

By the end of this lesson, you should be able to identify common computer devices and explain the basic input, processing, output, and storage process.

📘 Lesson 3: Internet & Websites

Learn what the internet is, how websites work, and how people access information online.

🌐 What Is the Internet?

The internet is a global network that connects computers and other devices so they can communicate and share information.

🖥️ What Is a Website?

A website is a collection of related web pages and other resources that can be accessed through the internet using a web browser.

🔗 What Is a Web Address?

A web address, also called a URL, is the address used to locate a particular resource on the internet.

For example, a website may have an address such as example.com.

🌍 Web Browsers

A web browser is software used to access and display websites.

Examples include Google Chrome, Microsoft Edge, Mozilla Firefox, and Safari.

🧩 How Does a Website Work?

When you enter a website address into a browser, the browser requests the website's resources from a server. The browser then displays the information on your screen.

🔐 Staying Safe Online

When using the internet, protect your accounts and personal information. Use strong passwords, be careful with unknown links, and avoid sharing sensitive information with untrusted people or websites.

🎯 Lesson Goal

By the end of this lesson, you should be able to explain the basic idea of the internet, identify what a website is, and understand the purpose of a web browser and web address.

📘 Lesson 4: Introduction to HTML

Learn how HTML gives a webpage its basic structure and how simple HTML elements are used to create web content.

🌐 What Is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on webpages.

🧱 HTML Creates Structure

HTML can be used to organize headings, paragraphs, links, images, lists, buttons, forms, and many other parts of a webpage.

🏷️ HTML Elements

HTML uses elements to tell the browser what different pieces of content represent.

For example, a heading can be written using: 

<h1>My Website</h1>

📝 Paragraphs

A paragraph can be created using the <p> element. 

<p>Welcome to my website.</p>

🔗 Links

Links allow users to move from one page or resource to another. 

<a href="cbt.html">Start CBT</a>

🧠 Remember

HTML is mainly concerned with the structure and meaning of webpage content. CSS is used to control presentation and JavaScript can be used to add interactive behavior.

🎯 Lesson Goal

By the end of this lesson, you should understand what HTML is and recognize some basic HTML elements used to structure a webpage.

📘 Lesson 5: Introduction to CSS

Learn how CSS controls the appearance, layout, spacing, and visual presentation of webpages.

🎨 What Is CSS?

CSS stands for Cascading Style Sheets. It is used to style and present HTML content.

🧱 HTML + CSS

HTML provides the structure of a webpage, while CSS controls how that structure looks.

✍️ Changing Text Appearance

CSS can change things such as text size, font, alignment, and spacing. 

h1 {
    font-size: 32px;
}

📦 Styling a Box

CSS can add backgrounds, borders, spacing, and rounded corners to elements. 

.card {
    padding: 20px;
    border-radius: 10px;
}

📐 Layout

CSS can help arrange webpage elements into rows, columns, grids, and other layouts.

📱 Responsive Design

CSS can also help webpages adapt to different screen sizes, such as phones, tablets, and computers.

🧠 Remember

HTML gives your webpage structure. CSS gives your webpage its visual appearance.

🎯 Lesson Goal

By the end of this lesson, you should understand what CSS is and how it is used to style HTML content.

📘 Lesson 6: Introduction to JavaScript

Learn how JavaScript adds interaction and dynamic behavior to webpages.

⚡ What Is JavaScript?

JavaScript is a programming language commonly used to make websites interactive and responsive to user actions.

🌐 HTML + CSS + JavaScript

A simple way to understand the three technologies is:

HTML → Structure

CSS → Appearance

JavaScript → Interaction

🧠 Variables

Variables allow a program to store information that can be used later. 

let studentName = "Emma";

🖱️ User Interaction

JavaScript can respond to actions such as clicking a button, entering information into a form, or selecting an option. 

function sayHello() {
    alert("Welcome!");
}

🔧 JavaScript on Your Website

JavaScript can be used to create features such as search boxes, menus, calculators, quizzes, CBT systems, forms, and interactive learning tools.

🎯 Lesson Goal

By the end of this lesson, you should understand the purpose of JavaScript and how it can make a webpage interactive.
